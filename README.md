# Domain Forge

面向后续项目复用、以 AI 研发和人工评审为主要协作方式的 DDD 微服务脚手架。

**当前阶段：现有设计已获人工接受，正在规划文档控制面与项目执行方式。** 批准基线为 DESIGN-v0.1，准确范围见[H02](docs/governance/review-register.md)。当前尚无应用源码或运行环境，未启动研发；本轮新增治理与规划方案仍为草案。

## 从这里开始

1. 从[文档入口](docs/README.md)查找每类事实的权威位置。
2. 阅读[文档控制面](docs/governance/document-control-plane.md)，审阅规划、规范、过程与交付物的治理方案。
3. 阅读[项目执行规划](docs/planning/project-plan.md)和[整体路线](docs/roadmap.md)，了解近期准备任务与完整阶段。
4. 按任务进入相关设计；人工接受与执行授权在[评审记录](docs/governance/review-register.md)登记。

## 核心入口

| 文档 | 唯一维护的内容 |
|---|---|
| [文档入口](docs/README.md) | 全部主题导航与权威来源 |
| [项目定位](docs/design/01-project-scope.md) | 产品边界、使用旅程与复用方式 |
| [文档控制面](docs/governance/document-control-plane.md) | 分类、生命周期、变更、证据与交付机制 |
| [项目执行规划](docs/planning/project-plan.md) | 当前前沿、近期任务和完成条件 |
| [整体路线](docs/roadmap.md) | 从准备、验证、IAM 到发行与技术扩展的阶段顺序 |

仓库内的 AI 工作规则见 [AGENTS.md](AGENTS.md)。所有运行时能力及未来验收用例均尚未执行；文档一致性检查不能替代兼容性测试或人工设计评审。
