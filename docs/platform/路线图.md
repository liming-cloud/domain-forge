### 收敛（2026-11-03 决定）

项目回顾后，首版暂停新增组件与新能力，先保证已有能力的质量、业务团队可用与 AI 研发效率。2026-11-05 按双北极星重排（取代 2026-11-03 的原顺序），方向由[质量模型与北极星](../platform/质量模型与北极星.md#北极星)中的双北极星判断。顺序由 blocked by 表达；就绪且依赖已关闭的任务中，编号小的优先。逐会话的推进与交接见[路线 issue #115](https://github.com/liming-cloud/domain-forge/issues/115)：

## 已知风险

- 消息鉴权：RocketMQ 未开启鉴权，只在内部网络可达，网段内的容器可以发布或消费任意主题；是否开启 ACL 需要人工决定。
- 定时任务服务端：PowerJob 官方镜像的运行时为 Java 8（1.8.0_292），控制台账号体系与 IAM 分离；控制台只在主机回环地址经覆盖文件发布。
- 依赖漏洞：Tomcat 11.0.24 有 11 项告警未处置，生产可利用性未评估。Dependabot 会持续提示。
- 会话安全：原生会话迟到写入由 SQL 许可兜底（许可缺失或凭据版本不符即拒绝）。许可提交失败、改密／禁用与登录竞争由 `IdentityPersistenceIT` 在真实 PostgreSQL／Redis 上验证。
- 数据库基线：P2 重写了 IAM 的 `V1__iam.sql`（主键改为 bigint、删除回执与补录表），P2 之前创建的本地库需重建。

P1 之前的逐层确认记录、验收依据和控制面实现保存在 git tag `governance-v1-archive`。
