## 范围与验收

当前设计引用[上下文](../architecture/01-总体架构.md#上下文模块与模型)、[组件分类](../architecture/01-总体架构.md#制品拆分与装配)与[查询短路径](../architecture/01-总体架构.md#纯查询最短路径)。不复制总体规范，不新增产品组件、服务或模板功能。仅本地实施及验证，不提交推送或修改 CI。

| 编号 | 验收出口 |
|---|---|
| 2A-A01 | 授权、工具版本和输入固定；不越过产品、CI 及版本边界 |
| 2A-A02—A03 | 真实 context 编译启动，扫描仅覆盖自身；四类职责反向 bootstrap、包根重叠及错身份被拒 |

| 2A-A07—A09 | 查询合同与实现真实绑定；最短路径与资源决策路径分别验证；HTTP／内部入口拒绝、范围、依赖失败、无写入与固定单 SQL／20 条上限可观察；SQL 所有权及业务语义单独评审 |

| 2A-A12 | 执行者语义评审、候选与人工清单准确；维护 Markdown ≤29，只新增本任务；告警和历史失败保留；远端及人工验收不由本地验证产生 |

原生新正反例、环境及验证输出保存于 `.run-artifacts/phase2a/`；尚未执行的场景不宣称通过。受控权限／SQL 夹具不构成 IAM 或企业性能交付。事件、事务、ACL 原则保持，新增实际能力在阶段 2b 及后续具体单元设计。
