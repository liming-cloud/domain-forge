| T-A05 参数 | 八个控制面子命令及 product 完整转交；缺参数、未知命令、缺评审或证据不放行 |
| T-A06 使用 | 根与仓库外 cwd、空格／中文路径可用；显式根与相对参数按原合同处理 |
| T-A07 失败 | stdout／stderr、stdin、退出码直通；实际中断与受控失败不变成成功 |
| T-A08 产品 | 47 项产品输入、18 JUnit、37 HTTP、55 产品反例保持；49 项合同来源只改两个场景路径，OpenAPI／GAV／版本不变 |
| T-A09 CI | 142 行／146 处路径逆映射等于原工作流；作业、组、条件、版本、缓存和预算不变 |
| T-A10 文档 | 仅新增本任务，最多 28 份维护 Markdown；单导航、当前入口及旧验收保留 |
| T-A11 执行 | 原 147 控制面回归、四类使用路径、新入口反例、完整适用校准与真实产品实际验证；环境缺口和失败分别记录 |
