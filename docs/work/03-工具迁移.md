| 标准 | 可观察出口 |
|---|---|
| T-A01 清单 | 121 项逐一对应，模式与字节差异可解释；无副本、软链接、空能力目录或未知文件清理 |
| T-A02 职责 | 三个工具区及直接入口保持；dev／cli 仅分派，产品不依赖工具、无新 POM |
| T-A03 输入与选择 | 旧真实删除项映射原责任，新活工具与 dev／cli 纳入输入及完整相关检查；旧活文件、未知和冲突拒绝 |
| T-A04 断言 | 124 个原检查定义、114 条校准命令／358 项原测试身份保留；路径归一后核对原断言，观测修复新增 2 项测试另计 |
| T-A05 参数 | 八个控制面子命令及 product 完整转交；缺参数、未知命令、缺评审或证据不放行 |
| T-A06 使用 | 根与仓库外 cwd、空格／中文路径可用；显式根与相对参数按原合同处理 |
| T-A07 失败 | stdout／stderr、stdin、退出码直通；实际中断与受控失败不变成成功 |
| T-A08 产品 | 47 项产品输入、18 JUnit、37 HTTP、55 产品反例保持；49 项合同来源只改两个场景路径，OpenAPI／GAV／版本不变 |
| T-A09 CI | 142 行／146 处路径逆映射等于原工作流；作业、组、条件、版本、缓存和预算不变 |
| T-A10 文档 | 仅新增本任务，最多 28 份维护 Markdown；单导航、当前入口及旧验收保留 |
| T-A11 执行 | 原 147 控制面回归、四类使用路径、新入口反例、完整适用校准与真实产品实际验证；环境缺口和失败分别记录 |
| T-A12 语义 | 检查旧责任、新入口和证据闭环；真实远端与人工验收独立保留，不由本地绿灯产生 |

公开用法与边界只维护于[控制面机制](../workflow/03-研发控制机制.md#公开命令与记录字段)。本任务虽属于治理变更，仍按批准范围额外完整执行真实产品入口，不把 route 中产品阶段的延期标记当作本批免检。历史证据中的旧路径保持原样；维护、产品、原生命令及声明路径使用 harness。
