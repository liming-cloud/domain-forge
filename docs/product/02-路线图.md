## 阶段计划

| 阶段 | 内容 | 状态 |
|---|---|---|
| P1 治理重构 | 质量规则迁入 Maven；删除自建控制面与过程记录；CI 简化；流程改为 PR 评审；规范改写为规则卡；研发改为按验收跟踪 issue 推进 | 进行中 |
| P2 IAM 收口 | 会话设计定稿为“SQL 许可 + 凭据版本”；去掉 projectId、服务证书身份、iam-client 模块、命令回执与补录审计；事务改用原生 `@Transactional`／`TransactionOperations`；ID 定稿为雪花 bigint；配置改为 YAML | 已完成 |
| P3 模板同仓库化 | 模板生成到 `platform/services/<name>` 并加入聚合；附示例用例；删除独立消费工程与合同快照 | 已完成 |
| P4 MVP 闭环 | 一个业务服务从模板生成、接入 IAM、整套部署跑起来（`scripts/verify_closure.sh`） | 已完成 |
| P6 MVP 后能力 | 账号并发 CAS、Nacos 配置中心、API 网关、跨服务调用、消息与 Outbox、HTTPS 覆盖文件；各项决定见对应设计文档 | 已完成 |
| P7 首版剩余能力 | 按[首版跟踪](#首版跟踪)中未关闭的跟踪 issue 推进（含 P5 AI 研发效果度量） | 进行中 |

## 已知风险

- 消息鉴权：RocketMQ 未开启鉴权，只在内部网络可达，网段内的容器可以发布或消费任意主题；是否开启 ACL 需要人工决定。
- 定时任务服务端：PowerJob 官方镜像的运行时为 Java 8（1.8.0_292），控制台账号体系与 IAM 分离；控制台只在主机回环地址经覆盖文件发布。
- 依赖漏洞：Tomcat 11.0.24 有 11 项告警未处置，生产可利用性未评估。Dependabot 会持续提示。
- 会话安全：原生会话迟到写入由 SQL 许可兜底（许可缺失或凭据版本不符即拒绝）。许可提交失败、改密／禁用与登录竞争由 `IdentityPersistenceIT` 在真实 PostgreSQL／Redis 上验证。
- 数据库基线：P2 重写了 IAM 的 `V1__iam.sql`（主键改为 bigint、删除回执与补录表），P2 之前创建的本地库需重建。

P1 之前的逐层确认记录、验收依据和控制面实现保存在 git tag `governance-v1-archive`。
