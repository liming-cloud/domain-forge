# 0007 适配器的依赖方向

- 状态：已接受（2026-11-05）
- 关联 issue：[#93](https://github.com/liming-cloud/domain-forge/issues/93)、[#107](https://github.com/liming-cloud/domain-forge/issues/107)

## 背景

五个职责包的依赖方向允许 `interfaces` 经由 `application` 间接使用领域类型，也没有禁止 `infrastructure` 依赖 `interfaces`。2026-11-05 测得 IAM 中 `interfaces → domain` 有 6 个文件，`infrastructure → interfaces` 为 0。

## 决定

- `interfaces` 不依赖 `domain`，只认识 application 的命令、查询和视图。
- `infrastructure` 不依赖 `interfaces`，适配器之间只经端口协作。

## 后果

规则写入 [S-01](../rules/02-系统设计.md#s-01-五个职责各管各的事)；自动检查与 IAM 的 6 个违例由 [#107](https://github.com/liming-cloud/domain-forge/issues/107) 处理。
