# 0019 短信真实发送移出首版

- 状态：已接受（2026-11-03）
- 关联 issue：#113

## 背景

首版没有真实短信账号，且产品范围不含手机号登录，原定的真实发送与模板示例需要调整。

## 决定

- **真实发送**：移出首版：首版以协议替身验证请求与失败处理；真实发送在提供阿里云账号、已审核的签名与模板后手动执行一次 `AliyunSmsLiveIT`，跟踪见 [#113](https://github.com/liming-cloud/domain-forge/issues/113)
- **验证码接入示例**：不在服务模板中加示例（产品范围不含手机号登录与短信注册，模板没有使用方）；接入方式以[短信与验证码](../reference/components/notification.md#服务中的写法)的示例代码说明

## 后果

合同与用法见[短信与验证码](../reference/components/notification.md)；取代 [0018](0018-短信与验证码的取舍.md) 中“服务商与真实接入”一行。
