# 0017 文件存储的取舍

- 状态：已接受（2026-10-29）
- 关联 issue：#38

## 背景

文件存取需要选定访问方式、S3 对接、文件信息的事务归属与部署形态。

## 决定

- **安全访问**：经业务接口转发：业务授权后由组件流式读写；不签发直链或预签名链接，存储不对外暴露
- **S3 对接**：AWS SDK for Java v2（`s3` 2.57.6，同步客户端＋SDK 默认的 HTTP 客户端）；验证对象为 SeaweedFS 4.51 的 S3 接口（MinIO 已不再公开发布镜像）。不承诺所有服务商与全部 S3 功能
- **文件信息**：组件元数据表 `domainforge_file`，与业务数据同事务提交；业务只保存文件 ID
- **部署**：部署参考使用本地存储：每个服务一个命名卷，随 `backup.sh`／`restore.sh` 一起备份恢复。S3 只在组件集成测试中验证，部署参考不提供对象存储服务

## 后果

合同与用法见[文件存储](../reference/components/file-storage.md)。
