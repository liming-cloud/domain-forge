# 0009 失败模型与协议

- 状态：已接受（2026-11-05）
- 关联 issue：[#93](https://github.com/liming-cloud/domain-forge/issues/93)、[#105](https://github.com/liming-cloud/domain-forge/issues/105)

## 背景

失败没有统一的类型：领域层有 54 处通用异常；业务拒绝返回 200 加业务码，与 HTTP 语义和 RFC 9457 不一致；业务异常要按确切类型逐个登记映射。

## 决定

- 失败分为业务拒绝、依赖不可用、程序错误三类。`shared` 定义业务规则违反和依赖不可用两个基类；web-support 是唯一分派点，组件不注册全局异常处理。
- 业务拒绝改用 4xx 和 Problem Details（RFC 9457），属于不兼容的合同变更；与失败模型在同一任务中完成。

待决定：成功响应是否继续使用 `ApiResponse` 外壳；业务拒绝用哪些 4xx 状态码。两者在 [#105](https://github.com/liming-cloud/domain-forge/issues/105) 中答复。
