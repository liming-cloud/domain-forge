# 0011 配置中心的取舍

- 状态：已接受（2026-10-27）
- 关联 issue：#42

## 背景

接入 Nacos 配置中心时，无法应用的发布值、启动失败、种子来源与账号需要定下行为。

## 决定

- **无法应用的发布值（越界、类型错误）**：整组配置不应用，继续使用当前生效值，记录错误日志与指标；发布方修正后自动生效。O-09 相应修订，仍不做内容审核或拒收
- **启动时连不上 Nacos**：启动失败，不用本地默认值或客户端快照代替 Nacos 的值；Compose 重启策略负责重试
- **初始配置来源**：仓库维护种子，`nacos-init` 只在 dataId 不存在时发布；之后以 Nacos 中的内容为准，重新部署不覆盖
- **服务读取配置的账号**：共用现有服务账号，增加命名空间内配置只读权限；发布只由 Nacos 管理员进行

## 后果

合同与用法见[配置中心](../reference/components/config.md)。
