# 0020 请求幂等的取舍

- 状态：已接受（2026-10-29）
- 关联 issue：#37

## 背景

业务命令的重复提交需要统一的合同、范围与验证用例。

## 决定

- **合同**：`Idempotency-Key` 请求头（与 IETF Idempotency-Key 草案一致），重复请求原样返回首次结果
- **范围**：键与账号、接口绑定，保存 24 小时；处理中的并发重复 409，同一键但请求不同 422
- **验证用例**：模板便笺示例的创建接口

## 后果

合同与用法见[请求幂等](../reference/components/idempotency.md)。
