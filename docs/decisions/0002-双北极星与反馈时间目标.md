# 0002 双北极星与反馈时间目标

- 状态：已接受（2026-11-05）
- 关联 issue：[#93](https://github.com/liming-cloud/domain-forge/issues/93)、[#103](https://github.com/liming-cloud/domain-forge/issues/103)

## 背景

需要用少数指标判断方向是否正确：既要看 AI 研发交付的价值，也要看工程质量本身。

## 决定

- 价值北极星：AI 一次通过率和中位交付周期。
- 质量北极星：原则可执行率和变更局部性。
- 护栏：逃逸缺陷数不上升。
- 领先指标中的反馈时间目标：单模块门禁 ≤ 3 分钟，本地完整门禁 ≤ 15 分钟，CI 墙钟 ≤ 12 分钟。

各指标的口径见[质量模型与北极星](../platform/质量模型与北极星.md)。

## 后果

- 反馈时间目标写入规则卡 [T-13](../rules/10-测试与验证.md#t-13-反馈时间有上限)。
- 指标统计由 [#103](https://github.com/liming-cloud/domain-forge/issues/103) 实现。
