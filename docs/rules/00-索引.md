# 规则卡索引

规则卡是本仓库工程规则的唯一正文。本页只做索引，不写规则正文；每张卡只在一处维护，其他地方用卡号链接。

## 卡片格式

每张卡的标题为 `### <卡号> <规则名>`，卡号由前缀和两位数字组成，只增不复用。卡片包含：

- **规则**：必须做到的事。
- **理由**、**正例**、**反例**：按需提供。
- **状态**：可选。规则已决定但实现或自动检查尚未跟上时，写明差距和负责的 issue。状态为“待修订”的卡，正文描述当前实现，新代码按正文写；负责的 issue 修订正文时删除状态行（待修订清单见对应 ADR 的“后果”）。
- **检查**：由谁发现违规。写成用“；”分隔的若干段，每段以检查标签开头，可带“：说明”；同类标签用“、”并列。

| 检查标签 | 含义 |
|---|---|
| `自动[名称]` | 由 `mvn verify` 中的检查、CI 或组件的启动／运行时校验自动拦下；名称是架构规则标签（如 `职责归属`）、Checkstyle 模块或组件机制 |
| `测试` | 规则要求改动方编写的测试，随 `mvn verify` 执行 |
| `评审` | 由人工评审判断 |

`scripts/check_doc_links.py` 检查：卡号唯一；所有卡号引用都指向存在的卡；本页覆盖全部卡；检查标签合法。
